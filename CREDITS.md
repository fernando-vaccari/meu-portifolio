# Créditos das imagens

Layout, textos, marcas fictícias e código foram criados para este portfólio. Imagens ilustrativas foram obtidas dos projetos abaixo, sem copiar seus layouts. Todos os arquivos são servidos localmente.

- **Dentelo**, codewithsadee: `dental-hero.png` e `dental-about.png` (originais `hero-banner.png` e `about-banner.png`). Fonte: https://github.com/codewithsadee/dentelo. O README declara: “This project is free to use and does not contains any license.”
- **Barber**, codewithsadee: `barber-hero.jpg`, `barber-detail.jpg` e `barber-interior.jpg` (originais `hero-banner.jpg`, `gallery-1.jpg`, `gallery-3.jpg`). Fonte: https://github.com/codewithsadee/barber. O README declara: “This project is free to use and does not contains any license.”
- **Grilli**, Sadee: `restaurant-hero.jpg`, `restaurant-about.jpg` e `dish-1.png` a `dish-4.png` (originais `hero-slider-1.jpg`, `about-banner.jpg` e `menu-1.png` a `menu-4.png`). Fonte: https://github.com/codewithsadee/grilli. Licença MIT reproduzida abaixo.

Pessoas, ambientes e pratos são ilustrativos. Não representam clientes de Fernando, membros de empresas reais ou receitas específicas.
